# 📞 AI Voice Call Script Generator
### From SAS Recommendations → AI Prompts → Personalized Voice Calls

This module transforms recommendations produced by **SAS CI360** into warm and natural **voice call scripts** generated by an AI model.  
It enables personalized wellbeing check-in calls for elderly users based on up-to-date behavioral data.

---

## Purpose

SAS CI360 analyzes user activity, communication patterns, and daily events to generate individualized recommendations.  
This component takes those recommendations and uses them to create simple, friendly phone call scripts suitable for automated calling systems.

---

## Workflow Overview

1. **SAS CI360 generates daily recommendations**
   - Example: “User needs to go for a walk or exercise”
   - Context examples: “Low step count”, “It’s been a while since your last call”

2. **Recommendation data is exported as a CSV**
   The CSV includes:
   - `Name`
   - `Recommendation`
   - `Recommendation Context`

3. **The Python module loads the SAS data**
   The file is parsed using Pandas.

4. **A simple AI prompt is created**
   The prompt includes:
   - The person’s name  
   - Their SAS recommendation  
   - The recommendation context  

5. **Gemini AI generates the voice call script**
   The output:
   - 5–7 sentences  
   - Warm, friendly, and easy to understand  
   - Sounds like a real human checking in on the user  

6. **The script is ready for automated calling systems**
   These calls encourage physical activity, social connection, and event participation.
